PR merged into develop

The workflow runs only for merged PRs targeting develop, regardless of author. Opened PRs and closed-but-unmerged PRs do not trigger this workflow. The event goes to David through an active MCP subscription, with no periodic GitHub checks.

Samson’s role

Samson hosts the authoritative development workspace. Cloud tasks use its private HTTPS API through Tailscale for Linux builds, tests, file changes and isolated previews. The notification path does not depend on Samson.

Its project account has no sudo, GitHub write credential or production deployment token. Development D1 is separate from production data.

Release gates

  • Unexpected author or merge actor: alert Blake and pause.
  • Failed or incomplete checks: no production-ready claim.
  • Develop changed: verify the new candidate before release.
  • Production release: explicit owner approval and owner merge.
A delivery receipt confirms the event arrived. It does not prove David completed the work or that a release is ready.
